Student assessment accounting system
=
## Система учёта оценок студентов

В информационной системе будет учитываться личные данные
студентов и преподавателей (Ф.И.О., логин, пароль и т. д.), список
учебных дисциплин и групп студентов. Также в системе будет
отслеживаться успеваемость студентов и оценки за сессии.

### Цели системы

1. Перевод учета оценок студентов в электронную форму, что гораздо удобнее как для студентов, так и для преподавателей.
2. Обеспечить студентам полную прозрачность и доступность успеваемости в любое время.
3. Автоматизация отчетов по учебным дисциплинам, таких как средний балл.

Эта система полезна для студентов тем, что они
в любой момент самостоятельно могут узнать свои 
оценки и задолженности и вовремя исправить их. 
Также эта система приносит большую пользу 
преподавателям, им гораздо проще выставлять оценки 
электронно чем вручную заполнять журнал, помимо 
этого, система решает проблему с расчетом среднего 
балла и итоговых оценок.
### Пользователи системы
**Студент**: Роль студента в системе заключается в просмотре информации о своей успеваемости, такой как оценки. Он не может их изменять, как и прочие данные в системе.

**Преподаватель**: Он может изменять и добавлять информацию по своей дисциплине. Изменять оценки других преподавателей и прочую информацию он не может.

**Администратор**: Он имеет полный доступ к системе, а также может управлять всей информацией в ней, в том числе изменять и удалять её. Администратор может назначать преподавателей на дисциплины и добавлять студентов в группы.

### Основные функции системы
- Регистрация, авторизация и возможность выбора профиля
- Возможность выставления и просмотра оценок
- Расчет среднего балла по дисциплине
- Контроль посещаемости

### Архитектура и способы реализации

В системе будет использоваться классическая трёхуровневая архитектура:

1. Слой представления для взаимодействия пользователя с системой через консоль. Этот слой отвечает только за ввод и вывод данных.

2. Слой логики для обработки информации введённой пользователем и внутренних расчётов в системе, таких как расчёт среднего балла.

3. Слой данных для хранения всей информации.

Проект будет реализован c помощью языка программирования Python 3.14, и будет представлять собой консольное приложение.
